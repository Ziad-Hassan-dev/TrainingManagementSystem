Training Management System

About The Project
Training Management System is an educational web application built using ASP.NET Core MVC.
It helps manage training operations, including departments, instructors, courses, trainees, enrollments, and results.

Technologies Used
- C#
- ASP.NET Core MVC
- Entity Framework Core
- LINQ
- SQL Server
- HTML & CSS

Features
- Manage Departments (CRUD).
- Manage Instructors (CRUD).
- Manage Courses (CRUD).
- Manage Trainees (CRUD).
- Manage Course Enrollments (CRUD).
- Manage Course Results (CRUD).
- Database operations using Entity Framework Core.
- Validation and error handling.

Project Structure
The project follows the ASP.NET Core MVC architecture:

- Models
- Views
- Controllers
- DbContext
- ViewModels
- Validations

Getting Started

1. Clone the repository:
   git clone https://github.com/Ziad-Hassan-dev/TrainingManagementSystem.git
   
2. Open the solution in Visual Studio.
3. Configure your SQL Server connection string in "appsettings.json".
4. Apply database migrations: 
   Update-Database
5. Run the application.
